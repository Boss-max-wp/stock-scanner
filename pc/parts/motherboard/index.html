主機板推薦與價格比較（2026）

所有零件都插在它上面。挑的時候看三件事：腳位要跟 CPU 一樣、記憶體代數（DDR4 或 DDR5）、尺寸（E-ATX 加大 / ATX 大板 / mATX 小板，要放得進機殼）。

怎麼選

  • 先看腳位：AM5 給新的 AMD，LGA1851 給 Core Ultra，LGA1700 給 12～14 代 Intel，AM4 是舊 AMD。
  • 型號字母：A / H 入門，B 主流（一般人選這個），X / Z 高階。
  • mATX 跟 ATX 效能一樣，差在大小和插槽數量。
  • 名字有 WIFI 的才有無線網路，沒有的要插網路線。
