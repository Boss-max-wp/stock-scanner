負責畫面，玩遊戲時最重要也最貴的零件。很耗電，要注意電源夠不夠、機殼放不放得下（看長度 mm）。CPU 有內顯的話可以先不買。

怎麼選

  • 看螢幕選：1080p → 5060 / 9060 XT；2K → 5070 / 9070；4K → 5080。
  • 數字越大越強：5050 < 5060 < 5060 Ti < 5070 < 5070 Ti < 5080。
  • GB 是顯卡自己的記憶體，新遊戲用 8GB 開始吃緊，有預算選 12～16GB。
  • RTX（NVIDIA）光追、DLSS、剪片和 AI 支援比較好；RX（AMD）同價錢 GB 比較大。
  • 5070 Ti、5080 原價屋標「限搭機」，要跟其他零件一起買才賣。
