常見問題

顯卡要多少錢才夠玩遊戲？

只玩英雄聯盟、特戰英豪這類網遊，1 萬左右的 RX 7650 GRE 就很夠；想玩 3A 大作 1080p 中高畫質，抓 1.5 萬（RX 9060 XT 或 RTX 5060）；2K 螢幕建議 2.5 萬以上（RX 9070 或 RTX 5070）。

顯卡 8GB 夠用嗎？

1080p 大部分遊戲還夠，但新的 3A 遊戲開高畫質已經會吃滿 8GB。預算夠的話選 12～16GB，可以用比較久。

NVIDIA 和 AMD 顯卡哪個好？

同價位 AMD（RX）通常純遊戲效能比較好、顯存比較大；NVIDIA（RTX）的 DLSS、光線追蹤、剪片和 AI 軟體支援比較好。只打遊戲看 CP 值選 AMD，會剪片或玩 AI 選 NVIDIA。

顯卡要配幾瓦的電源？

RTX 5060 / RX 9060 XT 建議 550W 以上，RX 9070 / RTX 5070 建議 650W，RX 9070 XT / RTX 5070 Ti 建議 750W，RTX 5080 建議 850W，至少買金牌。

怎麼選

  • 看螢幕選：1080p → 5060 / 9060 XT；2K → 5070 / 9070；4K → 5080。
  • 數字越大越強：5050 < 5060 < 5060 Ti < 5070 < 5070 Ti < 5080。
  • GB 是顯卡自己的記憶體，新遊戲用 8GB 開始吃緊，有預算選 12～16GB。
  • RTX（NVIDIA）光追、DLSS、剪片和 AI 支援比較好；RX（AMD）同價錢 GB 比較大。
  • 5070 Ti、5080 原價屋標「限搭機」，要跟其他零件一起買才賣。
