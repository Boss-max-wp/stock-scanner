    出題範圍
    要考哪些單元

    詞性小抄（看字尾猜詞性）
    名詞 n.（人、事、物）：-tion、-sion（information）、-ment（payment）、-ness（business）、-ity（ability）、-ance / -ence（attendance）、-er / -or（manager、supervisor）、-ee（employee）、-ship（leadership） 動詞 v.（動作）：-ize（organize）、-ify（notify）、-en（widen）、-ate（coordinate） 形容詞 adj.（形容人事物）：-ful（helpful）、-ive（expensive）、-able / -ible（available）、-al（annual）、-ous（numerous）、-ic（basic）、-ent / -ant（efficient）、-ory（mandatory） 副詞 adv.（形容動作或形容詞）：大多是「形容詞 + ly」（quickly、carefully） 小心例外： ・-ly 結尾但是形容詞：friendly、costly、timely、likely、daily ・-ate 有時是形容詞：accurate、private、appropriate ・-ing / -ed 結尾常常當形容詞：outstanding、upcoming、experienced、qualified ・沒有字尾的字（hire、cancel、venue）只能靠背，多聽多看就會記住

    多益第五大題很常考：四個選項是同一個字的不同詞性（例如 success、succeed、successful、successfully），要看空格前後判斷該填哪一種。題目不一定是你單元裡的字。

    詞性小抄（看不懂時打開）
    名詞（人、事、物）：常見結尾 -tion、-sion、-ment、-ness、-ity、-ance、-ence、-er、-or、-ee 動詞（動作）：常見結尾 -ize、-ify、-en、-ate 形容詞（形容名詞）：常見結尾 -ful、-ive、-able、-ible、-al、-ous、-ic、-ent、-ant 副詞（形容動詞、形容詞或整句）：大多是形容詞 + -ly 看位置判斷： ・a / an / the / our / his 後面 + 空格 + 名詞 → 形容詞 ・a / the / our 後面 + 空格，後面沒有名詞 → 名詞 ・to、will、can、should、please 後面 → 原形動詞 ・is / are / was / be / remain / very 後面描述主詞 → 形容詞 ・句子已經完整，空格在修飾動作或形容詞 → 副詞
